# Data Analyst Internship Project - SAM AI Technologies

This repository contains data analysis tasks performed on the Zomato Restaurant dataset as part of the Data Analyst Internship at SAM AI Technologies.

## Tasks Completed
- **Task 2: Cuisine Combination Analysis** - Identified top cuisine combinations and evaluated their rating patterns.
- **Task 3: Data Visualization** - Built interactive charts and distributions using Seaborn and Matplotlib.
- **Task 5: Votes Analysis** - Analyzed correlation between restaurant votes and average ratings using heatmaps.

## Tech Stack
- Python (Pandas, Seaborn, Matplotlib)
- Google Colab
